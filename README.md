# Leonardo Sánchez — Hojalatería y Zinguería

Sitio estático personalizado a partir de la estructura de `TuWebEnTresDias/demo-techista`, publicado en GitHub Pages.

## Desarrollo

No requiere dependencias ni compilación. Ejecutar `python -m http.server 8000` y abrir http://localhost:8000.

Fotos reales provistas por el negocio, convertidas a WebP y alojadas localmente. No se utilizan videos, imágenes de stock, testimonios de ejemplo ni parámetros de personalización de la demo. El formulario prepara una consulta para enviar por WhatsApp; no almacena datos.

## Publicación

GitHub Pages desde la raíz de la rama `main`. Enlaces y assets relativos para funcionar bajo `/leonardo-sanchez/`.
